# ぽちっと四字熟語 (Pochitto Yoji)

四字熟語の空いた1マスに入る漢字を選ぶ、毎日5問のクイズ。
pochitto games / iOS (Capacitor 7)

- 本体: `www/index.html` + `www/app.js`
- 問題データ: `www/yoji.js`（296語・読み・意味・難易度3段階）
- ネイティブ連携: `www/native.js`（AdMob / アプリ内課金 / ローカル通知 / シェア）
- ビルド: `codemagic.yaml`（Codemagic のクラウドMacでIPA作成 → App Store Connect）

## 遊び方
- **今日の5問**: 日付で問題が決まる（全員共通）。やさしい2・ふつう2・むずかしい1。4〜6択。2回まちがえると正解表示
- 結果は 🟩🟨🟥 でシェア。連続日数・過去問・バッジ12種
- **練習**: ライフ3つで連続正解に挑戦（リワードでコンティニュー）
- **図鑑**: 出会った四字熟語が読み・意味つきで貯まる

## 収益
- バナー（ホームのみ）／ インタースティシャル（練習8問正解ごと・初回起動から3日目以降）
- リワード動画（練習モードの「意味を見る」「2つ消す」・コンティニュー）
- 買い切り `pochittoyoji_premium` ¥300（広告なし＋ヒント無制限）

## 開発
ブラウザで `www/index.html` を直接開けば、広告・課金なしで遊べる（動作確認用）。
`www/native.js` の `IS_TESTING = true`（Googleテスト広告ID）のあいだは審査に出さないこと。
